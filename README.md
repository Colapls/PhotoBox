# PhotoBox 照片盲盒

**像开盲盒一样，重新发现自己的照片。**

一款纯本地运行的 Android 照片重发现应用。它把系统相册里的照片和视频随机排列，以类似短视频的方式逐张展示，让用户重新遇见自己可能已经忘记的回忆。

## 初衷

你有没有过这样的体验？

> 翻一整天相册都找不到想分享的那张，但随手往下滑一次，却撞见一张很久没看的照片——原来那天去了那家店，窗外刚好有那道光。

手机相册里堆着几千张照片，真正会被反复翻看的只有最近几周；更早的回忆被时间埋进数据库深处，相册 App 的"按时间倒序"排列让它们永远停在最末尾。系统相册擅长**管理**，却不擅长**重逢**。

PhotoBox 想做的事很简单：

- **把选择权交还给偶然**。不按时间、不按地点，随机抽出一张，模拟"翻开盲盒"那一刻的惊喜。
- **让人与旧照片重新建立关系**。一次"再见"可能就足以把一张被遗忘的照片重新放回生活里。
- **严格守住本地边界**。照片是最私人的数据，不上传、不分析、不联网，只在设备上完成洗牌、点赞、收藏和删除。

> 设计的初衷是：当用户某天随手打开 PhotoBox，能和三个月前、五个月前、一年前甚至更久之前的一张照片再次相遇，并因此想起当时的自己。

## 从痛点到功能

| 痛点 | 对应的 PhotoBox 功能 |
|---|---|
| 相册按时间倒序，老照片永远排不到眼前 | **随机照片流**：洗牌算法打乱顺序，全屏展示 |
| 翻找旧照片效率低，经常半途放弃 | **全屏 + 手势驱动**：上滑下一张、下滑上一张，连续浏览零摩擦 |
| 路过一张照片想重看，但当时没标记 | **双击点赞 + 收藏**：当场标记，事后在"个人中心"集中回顾 |
| 删除照片要在多个 App 间切换，状态易乱 | **应用内删除**：走系统确认流程，同时同步清理点赞、收藏和随机队列中的引用 |
| 想看"那天还拍了什么"，只能手动挑日期 | **当天相册**：照片流左滑进入，自动按拍摄当天聚合 |
| 一次想清理多张照片，操作繁琐 | **多选模式**：长按进入网格多选，批量收藏、取消收藏或删除 |
| 视频被埋在相册最末，几乎不被回看 | **混合媒体流**：照片、GIF、视频同等待遇，进入页面才解码、离开即释放 |
| 不同时间范围、不同类型的照片想分类看 | **内容筛选**：混合 / 仅照片 / 仅视频 × 多种时间范围 |
| 想量化自己"重逢"了多少回忆 | **个人中心**：相册总数、已浏览、点赞、收藏四项实时统计 |
| 第一次打开 App 不清楚能做什么 | **首次引导**：隐私说明 → 权限申请 → 手势教学三屏递进 |

## 功能

- **随机照片流**：全屏展示本地照片和视频，上滑下一张、下滑上一张，浏览完一轮后重新洗牌。
- **点赞与收藏**：双击或点击按钮点赞，收藏照片后可在个人中心独立查看。
- **删除**：通过系统确认流程删除原文件，并同步清理点赞、收藏和随机队列中的引用。
- **当天相册**：从照片流左滑进入拍摄当天的全部媒体，支持网格浏览和全屏查看。
- **多选管理**：在当天相册中长按照片进入多选模式，可批量收藏、取消收藏或删除。
- **媒体播放**：支持普通图片、GIF 动图以及视频播放。
- **个人中心**：展示相册总数、已浏览数量、点赞数量和收藏数量。
- **内容筛选**：支持混合、仅照片、仅视频模式，以及多种时间范围筛选。
- **首次引导**：首次启动展示隐私说明、媒体权限申请和手势引导。

## 隐私设计

PhotoBox 不要求注册或登录，不上传照片、视频或个人数据。

- 媒体文件始终保留在设备本地。
- 点赞、收藏、筛选和浏览进度仅保存在本机。
- 应用只读取用户授权的照片、视频和媒体位置元数据。

- Android 8.0（API 26）及以上
- JDK 17
- Android SDK 35
- Gradle 8.10.2

## 构建

克隆仓库后，在项目根目录执行：

```bash
# macOS / Linux
./gradlew :app:assembleDebug

# Windows
gradlew.bat :app:assembleDebug
```

调试包输出位置：

```text
app/build/outputs/apk/debug/app-debug.apk
```

运行单元测试：

```bash
./gradlew :core:common:testDebugUnitTest :feature:day:testDebugUnitTest
```

## 项目结构

```text
PhotoBox/
|-- app/                    # 应用入口、导航和依赖装配
|-- core/
|   |-- common/             # 通用调度器、日期和图片加载器
|   |-- data/               # MediaStore、Room、DataStore 和仓库
|   |-- media/              # 视频播放与媒体元数据 UI
|   `-- ui/                 # 主题和通用 UI
|-- feature/
|   |-- day/                # 当天相册、多选和全屏查看
|   |-- onboarding/         # 首次引导和权限申请
|   |-- profile/            # 个人中心、点赞和收藏列表
|   |-- settings/           # 内容与时间筛选、缓存和洗牌设置
|   `-- stream/             # 随机照片流
|-- build-logic/            # Gradle 约定插件
`-- docs/                   # 设计与实施文档
```

## 使用方式

- 上滑或下滑：切换照片和视频。
- 双击：点赞或取消点赞。
- 左滑：进入当前照片拍摄当天的相册。
- 长按照片：进入多选模式。
- 底部按钮：点赞、收藏或删除当前媒体。

## 当前限制

- 相册选择入口已经存在，但指定相册尚未完整接入随机流筛选。
- 应用锁尚未实现。
- 部分视频和设备格式的兼容性取决于系统 MediaStore 与设备解码能力。
