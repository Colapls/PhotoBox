## 💡 项目简介

你的相册里存放着成千上万张照片，但绝大多数旧回忆，都被系统相册**时间倒序**的逻辑永久掩埋。

我们习惯了主动翻找照片，却忘了**偶遇才是回忆最好的打开方式**。

**PhotoBox 照片盲盒** 是一款**纯本地、无联网、零隐私上传**的 Android 照片回顾工具。通过随机洗牌算法，打乱你的相册顺序，以短视频沉浸式滑动的方式，让你随机翻出许久未见的旧照片、旧视频，重新邂逅过往的美好。

✅ **不联网、不上传、不收集任何隐私数据**

✅ **随机盲盒流，打破时间排序的束缚**

✅ **照片/视频/GIF 全介质支持**

✅ **极简手势操作，沉浸式无干扰浏览**

---

## ✨ 核心功能

### 🎲 照片盲盒随机流

内置智能洗牌算法，完全打乱相册时间、地点排序，每次打开都是全新的回忆盲盒，浏览一轮后自动重新洗牌，永远有新惊喜。全屏沉浸式展示，告别传统相册的刻板浏览体验。

### 📱 极简手势交互

- **上滑**：下一张媒体内容
- **下滑**：上一张媒体内容
- **双击**：快速点赞收藏心动瞬间
- **左滑**：查看当日全部相册内容
- **长按**：进入多选批量管理模式

### 🎬 全媒体兼容播放

完美支持 **静态照片、GIF 动图、短视频** 混合流浏览。基于 Media3 构建媒体播放内核，页面离开自动释放资源，极低内存占用，流畅不卡顿。

### ❤️ 回忆收藏与统计

支持双击点赞、一键收藏心仪照片。个人中心实时统计：相册总数、已浏览数、点赞数、收藏数，量化你所有被重新拾起的回忆，专属你的生活纪念册。

### 📅 当日相册回溯

看到某张珍贵照片，左滑即可快速进入**当日相册**，自动聚合当天拍摄的所有照片视频，一键回溯当天的完整故事。

### 🗑️ 本地安全管理

支持应用内直接删除媒体文件，遵循系统官方确认流程，删除后自动同步清空点赞、收藏、随机队列中的对应引用，数据干净无冗余。同时支持批量多选收藏、批量删除，高效整理相册。

### 🔍 精细化内容筛选

自由切换浏览模式：混合媒体、仅照片、仅视频；支持多维度时间范围筛选，精准翻看特定时段的回忆，适配不同浏览需求。

### 👋 新手友好引导

首次启动递进式引导：隐私权限说明、媒体权限申请、手势操作教学，零基础用户也能一秒上手。

## 🔒 隐私安全设计（核心优势）

照片是用户最私密的数据，PhotoBox 全程坚守**本地离线原则**：

- ❌ 无联网请求、无后台上传、无数据采集
- ❌ 无需注册、无需登录、无账号体系
- ✅ 所有点赞、收藏、浏览记录仅保存在本机
- ✅ 仅读取用户主动授权的媒体文件，无多余权限
- ✅ 不分析、不备份、不泄露任何用户隐私内容

## 🛠️ 本地编译构建

如果你是开发者，可自行克隆项目编译运行：

```bash
# 克隆项目
git clone https://github.com/Colapls/PhotoBox.git
cd PhotoBox

# macOS / Linux 编译调试包
./gradlew :app:assembleDebug

# Windows 编译调试包
gradlew.bat :app:assembleDebug
```

编译产物输出路径：`app/build/outputs/apk/debug/app-debug.apk`

### 运行单元测试

```bash
./gradlew :core:common:testDebugUnitTest :feature:day:testDebugUnitTest
```

## 🏗️ 技术栈

项目采用当前 Android 最新主流技术栈，纯原生 Kotlin 开发，架构规范、代码整洁、易扩展：

- **语言**：Kotlin 2.0.21
- **UI 框架**：Jetpack Compose + Material 3 全量原生 UI
- **架构组件**：Navigation Compose、Hilt 依赖注入
- **数据存储**：Room 数据库、DataStore 偏好存储
- **媒体内核**：MediaStore、Media3 ExoPlayer
- **图片加载**：Coil 3.0（支持内存/磁盘双缓存、GIF 解码）
- **异步调度**：Kotlin Coroutines + Flow
- **构建工具**：Gradle Kotlin DSL、版本目录管理

## 📂 项目架构

采用**模块化分层架构**，功能解耦、职责清晰，便于迭代维护与二次开发：

```text
PhotoBox/
├── app/                 # 应用入口、全局导航、依赖装配
├── core/                # 核心基础模块（全局通用）
│   ├── common/          # 通用工具、调度器、图片加载封装
│   ├── data/            # 数据层：MediaStore / Room / DataStore 仓库封装
│   ├── media/           # 媒体播放、元数据解析核心能力
│   └── ui/              # 全局主题、通用 UI 组件
├── feature/             # 业务功能模块（单一职责）
│   ├── stream/          # 核心随机照片盲盒流
│   ├── day/             # 当日相册、多选批量管理
│   ├── profile/         # 个人中心、数据统计、收藏列表
│   ├── settings/        # 筛选设置、缓存配置、洗牌规则
│   └── onboarding/      # 首次启动引导、权限申请
├── build-logic/         # Gradle 构建约定插件
└── docs/                # 项目设计文档、开发说明
```

## 📌 当前版本限制 & 未来规划

### 当前 1.0.0 版本限制

- 自定义相册筛选功能尚未完全适配随机流
- 暂无应用锁隐私保护功能
